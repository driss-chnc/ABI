# ABI 🛍️

> **ABI — Style that defines you.**

ABI est un projet de site e-commerce dédié à la vente de vêtements et de chaussures.
L'objectif est de créer une expérience moderne, simple et agréable, aussi bien sur ordinateur que sur mobile.

## 🚧 État du projet

**En cours de développement**

Le projet est actuellement en phase de conception et de développement. De nouvelles fonctionnalités seront ajoutées progressivement.

## 🎯 Objectifs

* Créer une interface moderne et responsive
* Présenter les produits de manière claire et attractive
* Permettre aux utilisateurs de consulter les produits
* Mettre en place un système de panier
* Proposer différentes options de livraison
* Offrir une expérience utilisateur simple et intuitive

## 🛠️ Technologies utilisées

* HTML5
* CSS3
* JavaScript
* Git & GitHub

Le design du site repose principalement sur :

* ⚪ Blanc
* 🔴 Rouge `#991424`
* Une interface minimaliste et moderne
* Une typographie basée notamment sur **Montserrat** et **Abril Fatface**

## 🚀 Installation

Clonez le repository :

```bash
git clone https://github.com/driss-chnc/ABI.git
```

Accédez au dossier :

```bash
cd ABI
```

Puis ouvrez `index.html` dans votre navigateur.
